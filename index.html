Code Visualizer

open source

Step through real Java execution

I hit the limit on LeetCode's built-in debugger in the middle of a practice session, and rather than pay for it I wrote my own. Paste a Java class Solution, give it inputs, and step through the actual run: line highlighting, variable state cards, pointer markers. It launches a second JVM and traces it through the Java Debug Interface, reading real stack frame values rather than simulating execution or instrumenting bytecode. Runaway programs are bounded by a ten second timeout and a two thousand step cap, and the child process is always destroyed on cleanup. No Maven, Gradle, or npm: everything compiles with javac, and 13 test files run 324 assertions across the pipeline, including fixtures that deliberately hang, read out of bounds, and return the wrong answer.

T&D Landscaping

client work

A real client site, live in production

A landing page and work gallery built and shipped for a landscaping company in Naperville, Illinois. Hand written HTML, CSS, and JavaScript: no framework, no bundler, no build step. Around 690 lines of JavaScript carry a looping photo carousel that pauses for hover, focus, touch, tab visibility and reduced motion, plus a keyboard navigable lightbox with a focus trap, and an estimate form that falls back to a call or email prompt if submission fails. A token layer of CSS custom properties drives the palette and spacing scale, and the layout is mobile first. Deployed on Cloudflare Pages, where main ships to production and every other branch gets a preview URL for the client to approve first.

TikTok Trending Scraper

source available

Browser driven scraper for trending listings

A Java scraper that drives headless Chrome through Selenium to reach listings that only exist after the page renders, then makes a second pass with jsoup to pull Open Graph duration metadata for each link, selecting a batch under a duration budget. Recently revived: the pinned ChromeDriver had drifted 37 major versions behind the installed browser, and the target route now redirects to a login gated feed. The driver is current again and the scraper now targets /explore. An end to end run is still stopped by TikTok's bot detection, which the README states plainly rather than leaving implied.
